# Java ATM Simulation

A simple ATM Machine Simulation built using Java.

## Features
- PIN Authentication (3 attempts).
- Check Account Balance.
- Deposit Money.
- Withdraw Money.
- Show Account Status (VIP, Regular, Low Balance).
- Transaction Counter.
- Account Empty Warning.

## Technologies Used
- Java
- Scanner
- Loops (while, do-while)
- Switch Statement
- If-Else Statements

## Initial Settings
- PIN: `1234`
- Initial Balance: `2500.75`

## How to Run
1. Clone the repository.
2. Open the project in IntelliJ IDEA.
3. Run the `Main.java` file.
